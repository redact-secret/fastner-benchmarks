- performance protocol: Cells run serially on an otherwise unmanaged machine; the protocol does not control CPU frequency, thermal state or background load.
- performance protocol: Cold = a fresh process start with model files likely in the OS page cache after the first run; true cold-disk start is not forced.
- performance protocol: External-process adapters include JSON-lines serialization and pipe transfer in every latency; native adapters do not. Compare transports with that in mind.
